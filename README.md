# leetcode

A collection of solved LeetCode problems, mainly in PHP and Go, with some SQL and JavaScript.

## Context

Kept as regular algorithm practice for coding interviews from July 2023 to April 2025. Solutions were submitted on LeetCode and synced to this repository automatically by the LeetHub browser extension; solution commits carry the runtime and memory reported by LeetCode. The practice started in PHP, the owner's main language; Go solutions followed from August 2023.

## Features

- Close to 300 problem folders, mostly Easy, plus a few dozen Medium and a handful of Hard problems.
- Solutions by language (number of folders containing at least one file):
  - PHP: 180
  - Go: 71
  - SQL (database problems): 32
  - JavaScript: 16
- Each folder contains the problem statement (`README.md`); most also have a `NOTES.md`.
- Some problems are solved in more than one language, for example `0001-two-sum` in PHP and Go.

## Tech stack

- PHP
- Go
- SQL
- JavaScript
- LeetHub for syncing accepted submissions to GitHub

## Architecture

One folder per problem, named `<number>-<problem-slug>` as generated by LeetHub:

```
0001-two-sum/
  0001-two-sum.go     solution in Go
  0001-two-sum.php    solution in PHP
  README.md           problem statement
  NOTES.md            notes
```

Solutions follow the LeetCode format (a `Solution` class in PHP, a plain function in Go), so they are meant to be read or pasted into LeetCode rather than run as a standalone program. A few folders use older LeetHub naming (for example `1-two-sum`, `5-longest-palindromic-substring`).

## Getting started

Browse the folders on GitHub, or clone the repository and open any problem folder. To run a solution, paste it into the corresponding problem on LeetCode.

## Testing

There are no automated tests. Solutions were verified by the LeetCode online judge at submission time.

## Status

Active practice from July 2023 to April 2025 (most solutions in 2023 and 2024). No new solutions have been added since April 2025.
